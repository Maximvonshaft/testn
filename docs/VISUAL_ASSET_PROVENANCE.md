# Visual asset provenance and claim boundary

The scene-state atlases are controlled digital visualisations for the AQUASTONE website. They are not installed-project photography, laboratory measurements, or exact colour references for physical samples.

Permitted use: brand and application visualisation, responsive interaction acceptance, design-direction review and project discussion before physical sample approval.

They must not be represented as exact sample colour, completed-project photography, measured roughness/gloss/height data, certification evidence or performance evidence.

When controlled sample photography or scanning becomes available, the offline renderer must preserve system IDs, material order, atlas dimensions, filenames and public URLs. This allows product accuracy to improve without changing the web architecture.
